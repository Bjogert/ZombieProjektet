# Scope and explicit non-goals

## First playable slice
One small Swedish rural region, a few houses, roads, trees and water. Interactable home with a door, window, container and basic tool. One threat with sound attraction. Simple inventory and persistence. A few believable survival interactions.

## Mod branch
Verify Build 42 tool compatibility. Prefer built-in game mechanics and licensed/allowed mod dependencies. No custom engine.

## Standalone branch
Original assets, original code and independent game balance. Candidate: Godot 4 + C#, orthographic camera in a 3D world. No multiplayer until the single-player core feels good.

## Do not build for v0
Advanced NPC relationships, multiplayer or dedicated servers, new zombie species, giant crafting catalogs, hundreds of clothing items, perfect real-address interiors, or a bespoke engine.
