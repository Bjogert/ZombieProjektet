# Engine alternatives (not selected)

## Godot 4 + C# (leading candidate)
3D scene with an orthographic/isometric camera; mature tools and MIT-licensed engine. Risks include crowd AI, pathfinding, streaming, art pipeline and save compatibility.

## Bevy + Rust
Interesting ECS architecture and native Rust; greater tooling and integration burden and API churn.

## Unity + C#
Established engine and asset ecosystem; proprietary terms and licensing.

## Custom Rust engine
Not justified for an initial prototype.

## Open source inspiration
Cataclysm: Dark Days Ahead may inspire our own mechanics, but do not copy code/assets without reviewing licensing and derivative obligations.

Choose based on a tested vertical slice, not language fashion.
