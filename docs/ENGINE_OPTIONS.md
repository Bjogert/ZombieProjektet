# Fristående spelmotor — arkiverad framtidsidé

**Status: ej aktuell.** [ADR-0001](decisions/0001-mod-or-game.md) beslutade att ZombieProjektet utvecklas som en Project Zomboid Build 42 Stable-kartmod. Agenter ska **inte** undersöka, specificera eller bygga en Godot/Bevy/Unity-variant utan ett nytt uttryckligt beslut efter att kartmodden fungerar.

En eventuell fristående spelidé får behandlas som ett helt nytt framtida projekt med egna rättigheter, grafik och mekanik, inte som ett kompatibilitetskrav som belastar dagens kartgenerator.
